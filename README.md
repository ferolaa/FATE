# FATE — Data Privacy & Algorithmic Fairness

**Exploring data anonymization, privacy protection, and fairness in machine learning through practical Python exercises.**

## Project Overview

This repository contains practical laboratory work on **Fairness, Accountability, Transparency, and Ethics (FATE)** in data science and artificial intelligence.

The exercises investigate how personal data can be protected through anonymization techniques and how machine learning models can be evaluated for potential bias and unfair outcomes.

## Lab 1 — Data Anonymization

This laboratory explores privacy-preserving techniques for structured datasets.

**Topics covered:**
- Direct identifiers and quasi-identifiers
- K-anonymity and equivalence classes
- Data generalization and global recoding
- Microaggregation
- L-diversity
- Local suppression
- Privacy–utility trade-offs

**Notebook:** `Lab I - Data Anonymization/Notebook/L1_Data_Anonymization.ipynb`

## Lab 2 — Algorithmic Fairness in Regression

This laboratory examines fairness and potential bias in predictive models, using regression-based examples involving salary and law-school data.

**Topics covered:**
- Exploratory data analysis
- Linear regression
- Sensitive attributes and demographic differences
- Model performance across demographic groups
- Statistical and demographic parity
- Counterfactual fairness
- Fairness-aware preprocessing

**Notebook:** `Lab II - Algorithmic Fairness/Notebook/L2_Algorithmic_Fairness_I_Regression.ipynb`

## Getting Started

The exercises can be explored using Jupyter Notebook or JupyterLab.

Install the main Python libraries:

```bash
python -m pip install jupyter pandas numpy scipy scikit-learn matplotlib seaborn prettytable
```

Open the relevant notebook and run its cells in sequence. Some exercises require downloading external datasets referenced in the original course material.
